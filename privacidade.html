Política de privacidade

Esta política vale para o app Robô Marcelo, ferramenta pessoal de Marcelo Nogueira (@marcelonog76).

O que o app faz

Envia, agenda e confere vídeos no canal do YouTube do próprio Marcelo, usando a YouTube Data API (Serviços de API do YouTube).

Quais dados acessa

Apenas os dados do canal do Marcelo necessários para enviar vídeos, definir título, descrição e horário de publicação e consultar o status desses vídeos. O app não acessa dados de outros usuários nem de quem assiste aos vídeos.

Como guarda

A autorização do Google fica salva somente no computador do Marcelo. Nenhum dado é enviado a terceiros, vendido ou usado para publicidade.

Serviços do Google e do YouTube

Ao usar este app, valem os Termos de Serviço do YouTube e a Política de Privacidade do Google.

Como revogar o acesso

O acesso pode ser removido a qualquer momento em myaccount.google.com/permissions.
